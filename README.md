# GitHub Actions Practice

## About

This repository was created to learn and practice GitHub Actions by following the official GitHub Actions documentation.

## What I Learned

* Creating GitHub Actions workflows
* Understanding workflow syntax (YAML)
* Running workflows on push events
* Using GitHub-hosted runners
* Creating jobs and steps
* Viewing workflow logs and execution status

## Workflow File

The workflow file is located at:

```text
.github/workflows/github-actions-demo.yml
```

## Trigger

The workflow runs automatically when code is pushed to the repository.

## Sample Workflow Steps

1. Checkout repository code
2. Display a welcome message
3. Verify workflow execution
